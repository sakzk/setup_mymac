# Python Sample Project

This project is a minimal Python application using a sub-module, designed to verify that your LSP (e.g., `pyright`) is working correctly.

It consists of a `main.py` script that imports and uses a `Calculator` class from the `utils` directory.

## Prerequisites

This script has no external dependencies.

## Run

To run the application, execute the following command from within this directory:

```sh
python main.py
```
